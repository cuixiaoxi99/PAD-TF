# P1--P6 data

This directory contains the files used by PAD-TF transfer pairs P1--P6:

- P1/P2: METR-LA and PEMS-BAY
- P3/P4: PEMS04 and PEMS08
- P5/P6: PEMS03 and PEMS07

PEMS03, PEMS04, PEMS07, and PEMS08 are redistributed from
[FlashST-DATA](https://huggingface.co/datasets/bjdwh/FlashST-DATA), which is
marked Apache-2.0 by its publisher. METR-LA and PEMS-BAY values are
redistributed unmodified from [Zenodo record
5146275](https://zenodo.org/records/5146275), created by Semin Kwak and
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The sensor-graph files originate from the official
[DCRNN repository](https://github.com/liyaguang/DCRNN/tree/master/data/sensor_graph).

See [`docs/DATASETS.md`](../docs/DATASETS.md) for the complete expected layout
and provenance details.
